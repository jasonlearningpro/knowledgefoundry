# KnowledgeFoundry Author (tester preview)

A Windows desktop app for building eLearning courses. Course logic lives on a visible
flowchart instead of hidden triggers, and courses publish to cmi5, SCORM 2004,
SCORM 1.2 or plain web.

## Download

Get the installer from the **Releases** section on this page:
https://github.com/jasonlearningpro/knowledgefoundry/releases/latest

## Before you install

- **Windows 10 or 11, 64-bit.**
- **Windows will warn you.** This test version isn't signed, so Windows shows
  "Windows protected your PC." Click **More info**, then **Run anyway**.
- **Each test version works for 35 days** from its build date. The release notes
  show the last day. Your course files keep working in the newer version.

## Getting started

- **Help → Example courses** opens three finished courses to explore and take apart.
- **Help → User guide** (or F1) covers everything the app can do.

## Known limits

- Windows only.
- cmi5 packages haven't been tested in a real LMS yet. SCORM 2004 and SCORM 1.2 have.
- Not yet tested with a screen reader or on real phones.
- Auto-transcribe downloads a speech model the first time you use it.
