Add a hotspot

A hotspot is a clear, clickable area you place over part of a screen, for example over part of a picture. Use More → Hotspot, drag it over the area, and give it a name in the Name for screen readers box of the floating palette (it starts out as "Hotspot"): a screen reader reads that name, so say what happens ("Open the safety star"). In the editor it shows as a faint blue dashed box; learners see nothing, but keyboard users get a visible outline when they Tab to it. On the Flow Canvas, the screen gets an output named after the hotspot, which you connect like a button's. A hotspot is a rectangle for now.

Keep the markers in place on a phone

On a phone, the items you can select on a picture (hotspots, clickable shapes, the numbered markers of a Labeled graphic) are stacked as a list under the picture. To keep them over the picture instead:

  1. Select the picture.
  2. In Properties, under On a phone, the markers on this picture, choose Keep in place over the picture. The choice only shows when the picture has markers on it.
  3. Press Phone view in the live preview to check it.

In Phone view the markers stay on the picture:

The picture then fills the phone's width with the markers on it, scaled with it. Learners can still Tab to each marker and hear its name, and a small marker gets a finger-sized area around it that also selects it. This suits a picture with only a few markers, spread apart. With many markers close together, keep Stack as a list under the picture. A screen set to Keep this screen as drawn on small screens is not affected.
