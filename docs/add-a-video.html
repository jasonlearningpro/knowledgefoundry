Add a video

You can put a video on a screen. It is a file inside your course, so it works without the internet. MP4 and WebM files are supported.

  1. Select a screen and choose ▶ Video… above the stage (or + Import video… in the Assets tab and drag it onto the stage).
  2. Pick the file. It appears on the stage as a picture of its first moment. Move and resize it like any item.
  3. Select it. In Properties, give it a title (what a screen reader says), and Import captions… from an SRT or WebVTT file.
  4. Use Preview to try it. The learner presses play. A video never starts by itself.

Step 3, the video's title and captions in Properties:

Triggers. In Triggers, the actions Play a video and Pause a video let a button control it, and a video ends is an event you can wait for, for example to show a Continue button once the video has been watched. Use Preview to try it, since a video only plays after the learner has used the page.

Captions. People who cannot hear the video need them, and the checks warn when they are missing. The learner turns them on in the video's own controls.

Good to know. Keep videos small: a file over 60 MB, or a course over 100 MB, is flagged. Videos from YouTube or Vimeo links are not supported. There is no audio description track (a second sound track that describes the pictures); if what happens on screen is not in the speech, say it in the screen's text as well.
