Build the course flow (the Flow Canvas)

The Flow Canvas is the course's map. Each card is a step, and the wires between them decide what comes next. Nothing is hidden: if a learner can get somewhere, there is a wire that shows it.

CardWhat it does
StartWhere the course begins. A course has one.
ScreenA page the learner sees. Each button (or clickable item) on it adds an output socket to the card.
ConditionTests a variable, or a formula, and leaves by true or false.
Set variableSets, adds to, takes away from or switches a variable, then carries on.
QuestionOne question written on the card. Leaves by correct or incorrect.
QuizAsks questions drawn from the question bank (see Build a quiz).
ResultsShows the score. Leaves by passed, failed or retry.
CompleteEnds the course as Completed, Passed or Failed, and can report a score.
  • Add a card: right-click an empty spot on the canvas, use the Build tab, or press Ctrl+K and type "add".
  • Wire two cards: drag from an output socket on the right of one card to the next card. To remove a wire, select it and press Delete.
  • Move around: scroll to zoom, hold Space and drag to pan, and use the mini-map in the corner.
  • Tidy it: see Tidy up the Flow Canvas.
  • A card that nothing leads to, or a button with no wire, is listed by the checks (see Check the course for problems).
