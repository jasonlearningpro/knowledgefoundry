Check accessibility before you publish

In the Export dialog, press Check accessibility of the finished course. KnowledgeFoundry builds the course, opens it the way a learner's browser would, and an automatic checker (axe-core) looks at every screen, quiz and results page and the player around each (up to 40 pages). It lists what it finds, worst first, naming the screens each problem is on, with how many places and an example. A course with many screens takes a little while. If a problem is on every page it comes from the course player, so it is listed once. These are warnings; they never stop you from exporting. The same check runs after you export.

The button sits under the checks in the Export dialog (greyed here, because this picture was taken without the desktop app):

Reading order. Check course also warns when a screen reader would read a screen in an order that clearly differs from how it looks (for example the footer note before the heading). To change it, open the Layers panel and use Reading order. The order also decides how the screen is stacked on a phone. An automatic check finds only some problems. Also try your course with only a keyboard (Tab, Enter, Space), and with a screen reader such as NVDA or Narrator.
