Do math with variables (formulas)

A Condition node normally compares one variable with one value. To test something more, select the node and change Test to Formula, then type the test, for example var1 + var2 + var3 >= 2. It passes when the total is at least 2. A Set variable node (and the Compare to side of a normal Condition) can also use a formula: choose Formula in the kind-of-value list and type something like bonus * 2 + 1.

You can useExamples
Matha + b, a - b, a * 2, a / 4, brackets: (a + b) / 2
Comparisons= or ==, !=, <, <=, >, >=
Combine testsand, or, not: score >= 80 and tries < 3
Functionsmin(a, b), max(a, b), round(x), floor(x), ceil(x), abs(x)

True counts as 1 and false as 0, so you can add up yes/no variables: if seenA, seenB and seenC are yes/no variables, seenA + seenB + seenC >= 2 means at least two were seen. Variables hold plain numbers, so a percent such as quizPercent is compared with a plain number: quizPercent >= 80. The words true, false, and, or and not cannot be variable names.

Under the box, the app says what the formula means, or what is wrong with it. A formula that cannot be worked out while the course runs (for example, dividing by zero) counts as false and never stops the course. Export is blocked if a formula has an error (code VAL-E11), so you find out before you publish.
