Keep values in variables

A variable remembers something while the learner works through the course: a choice, a count, a score. Open the Variables panel and press + Variable. Give it a name (letters, numbers and _, starting with a letter or _), a Type (Number, Boolean for yes or no, or String for text) and the value it starts with.

  • Change it: with a Set variable card on the flow, or a trigger action (change a variable).
  • Test it: with a Condition card or a trigger's Only if.
  • Show it: put {{name}} in a text item, a button label or alt text (see Build a quiz → Good to know).
  • Rename it: type the new name in the panel. Every card, trigger and {{placeholder}} that uses it is updated.
  • While you preview, the panel has a Live column with each variable's current value.
  • Quizzes keep their own variables up to date, such as quizPercent (see Build a quiz).
