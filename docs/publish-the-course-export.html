Publish the course (export)

Choose File → Export… (Ctrl+E), or Export course on the Publish tab.

  1. Pick a package format. • cmi5: for a modern LMS or learning record store. Reports completion, pass or fail and score, resumes where the learner left off, and the pass or complete rule is built into the package. • SCORM 2004 (4th Edition): for most LMSs. The pass or complete rule is set in your LMS. • SCORM 1.2: the widest compatibility. One status (passed, failed or completed), a score from 0 to 100, and limited resume data. • Web (HTML5): no LMS. Open index.html, share a folder or host it anywhere. Nothing is tracked, so it suits review copies and demos.
  2. Check the course settings: the title, the pass or complete rule (for SCORM, set the same rule in your LMS) and the mastery score as a percentage.
  3. Read the checks. Errors must be fixed first; Show takes you to the problem. Check accessibility of the finished course runs the automatic accessibility check (see Check accessibility before you publish).
  4. Press Export, and choose where to save the package. Show in folder opens it in Explorer.
