Set the reading order

A screen reader reads a screen in a set order, and the Tab key moves through buttons in the same order. By default that order follows the layers, back to front, which is not always the order that makes sense (for example, the heading might be in front but should be read first). To change it, open the Layers panel and switch from Layers to Reading order. Select an item and press Read earlier or Read later (or drag it), until the list reads the way you want the screen read, first to last. This does not change what is in front. A new item is read last, and a copy is read right after the item it was copied from. Use layer order again puts it back. Applying a template to a screen resets its reading order.
